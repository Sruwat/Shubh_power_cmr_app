# Final Product Scope

The demo platform contains a native Expo mobile app, FastAPI backend, MongoDB Atlas-ready persistence layer, station import scripts, geospatial nearby search, demo OTP, backend-controlled demo charging, mock payments, wallet ledger, invoice/refund placeholders, support tickets, and APK-ready EAS configuration.

Real OCPP, SMS, production payment gateway, public backend hosting and EAS APK generation remain external-integration steps.
