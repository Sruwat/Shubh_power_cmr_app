# Mobile Architecture

- Framework: Expo React Native with TypeScript.
- Routing: Expo Router.
- Server state: TanStack Query.
- Auth storage: Expo SecureStore.
- Non-sensitive preferences: AsyncStorage ready dependency.
- Location: Expo Location, foreground only.
- Camera: Expo Camera on the Scan tab.
- Maps: React Native Maps.
- Forms: React Hook Form and Zod.

## Screens

- Onboarding
- Home
- Map
- Scan
- Activity
- Profile
- Station detail
- Active charging session

The app is native React Native, not a WebView and not the previous Vite prototype.
