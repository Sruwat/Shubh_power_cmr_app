# Product Requirements

## MVP Promise

A user logs in with mobile OTP, allows or bypasses location, sees nearby compatible chargers, opens station detail, starts a demo charging session on a demo-enabled Shubh station, monitors backend session state, stops charging, sees wallet/activity and opens support.

## Implemented Modules

- Onboarding and demo OTP.
- Location permission and manual fallback.
- Nearby station discovery.
- Map pins and list cards.
- Station detail.
- QR/manual charger validation.
- Demo charging session.
- Mock payment intent and completion.
- Wallet ledger.
- Activity history.
- Support tickets.
- Profile and demo vehicle creation.

## Out Of Scope For This Build

- Real charger control.
- Real payment gateway.
- Live provider availability.
- OCPI roaming.
- Fleet portal and full CPO CMS UI.
