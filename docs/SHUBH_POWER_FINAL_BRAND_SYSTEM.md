# Shubh Power Final Brand System

## Verified Identity

- Company: Shubh Power Solutions.
- Positioning: renewable power and EV charging infrastructure provider.
- Primary brand color: `#1388d7`.
- Secondary color: `#1cbfaa`.
- Dark navy: `#16163f`.
- Ink: `#20252d`.
- Body text: `#575a7b`.
- Border: `#dee2e6`.
- Warning gold: `#d3b574`.
- Error red: `#f5543f`.
- Typography source: Plus Jakarta Sans on the website; mobile uses system fallback unless native font bundling is added.

## Product Voice

Clear, operational and reassuring. The app avoids unsupported claims such as "available now" unless backed by real status integration.

## Mobile Application Decisions

- Teal means demo available or positive status.
- Gray means unknown/research status.
- Blue means primary action or selected state.
- Every status also includes text, not color alone.
