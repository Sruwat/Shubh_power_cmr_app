# Physical Android QA Checklist

- Install preview APK on a physical Android phone.
- Confirm API points to a public HTTPS backend, not localhost.
- Test location permission allowed.
- Test location permission denied.
- Test GPS disabled flow.
- Test manual location search.
- Test map rendering.
- Test small-screen layout.
- Test QR camera permission.
- Test manual charger ID.
- Test active session background/foreground recovery.
- Test slow network and backend timeout.
- Test token refresh after app restart.
- Test Google Maps navigation deep link.
- Test wallet top-up and support ticket creation.
